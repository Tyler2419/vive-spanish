# Vive Spanish

A phone-first Latin American Spanish practice app with a Colombian flavor.

## Practice Modes

- Spaced flashcards for practical phrases
- Listening scenes with browser speech playback
- Speaking/shadow practice with optional recording
- Phrase-builder game
- Daily immersion missions
- Local journal and streak tracking
- Slang deck with usage notes for casual or careful phrases
- Conversation packs, weekly recap, unlocks, and progress export/import

## Phone-First Use

The app is a static PWA. Once it is published on HTTPS, open the URL on your phone and use the browser's Add to Home Screen or Install option.

Progress is saved locally on the device/browser. For now, use the phone as the main device so progress follows you at home, work, and on the road.

## Local Run

```powershell
.\run_app.ps1
```

Then open the printed local URL.
